## معرفی پروژه

[پورتفولیوی یونس عباسی](https://younesabbasi.com/) بستری شخصی برای معرفی پروژه‌های وردپرس، توسعه وب و سئو در قالب نمونه‌کارهای ساختاریافته و Case Studyهای کامل است.

در معماری پروژه، مدل محتوایی پورتفولیو از لایه نمایش جدا شده است. نوع نوشته اختصاصی، دسته‌بندی‌ها، متادیتا، گالری و کنترل‌های امنیتی در MU Plugin قرار دارند؛ قالب نیز صفحه اصلی، آرشیوها، کارت‌ها، صفحات تکی و رابط واکنش‌گرا را مدیریت می‌کند.

## دستاوردهای اصلی

- ایجاد نوع نوشته اختصاصی Portfolio و Taxonomy سلسله‌مراتبی پروژه‌ها.
- نگهداری مدل محتوایی در MU Plugin برای مستقل ماندن اطلاعات از قالب.
- تعریف اطلاعات ساختاریافته پروژه شامل کارفرما، تاریخ‌ها، وضعیت، موقعیت و لینک بیرونی.
- گالری مرتب‌شونده مبتنی بر Media Library با چیدمان افقی یا عمودی برای هر تصویر.
- آرشیو، فیلتر دسته‌بندی، کارت‌های واکنش‌گرا و قالب کامل Case Study.
- نمایش پروژه‌های منتخب صفحه اصلی با ترتیب دستی و بدون تکرار Markup.
- مدیریت مرکزی تصاویر جایگزین، ویژگی‌های Lazy Loading، تاریخ‌ها و متادیتا.
- ضداسپم چندلایه دیدگاه‌ها بدون CAPTCHA.
- صفحات مدیریتی سفارشی برای پروفایل، مهارت‌ها، خدمات، سوابق، پیشنهادها و اطلاعات تماس.
- بارگذاری محلی وابستگی‌های فرانت‌اند و استفاده از Assetهای مدیریتی فقط در صفحات لازم.

## بخش‌های فنی مهم

### انتشار ساختاریافته پروژه‌ها

هر پروژه می‌تواند عنوان، خلاصه، محتوای کامل، تصویر شاخص، دسته‌بندی، تاریخ تحویل، اطلاعات کارفرما، وضعیت، موقعیت، لینک خارجی و گالری مرتب‌شده داشته باشد.

### کشف و مرور پروژه‌ها

آرشیو پورتفولیو شامل فیلتر Taxonomy، کارت‌های واکنش‌گرا، تشخیص جهت تصاویر و صفحه‌بندی است. پروژه‌های منتخب صفحه اصلی نیز با \`post__in\` و \`orderby => post__in\` دقیقاً به ترتیب انتخاب‌شده نمایش داده می‌شوند.

### مدیریت اختصاصی

بخش‌های Settings API برای پروفایل، زبان‌ها، مهارت‌ها، دانش فنی، خدمات، شبکه‌های اجتماعی، توصیه‌نامه‌ها، سوابق و تماس طراحی شده‌اند. فیلدهای تکرارشونده قابل مرتب‌سازی هستند و پیش از ذخیره پاک‌سازی می‌شوند.

### امنیت کاربردی

ذخیره اطلاعات مدیریت با Nonce، بررسی سطح دسترسی، جلوگیری از Autosave نامعتبر، Allowlist و Sanitization انجام می‌شود. فرم دیدگاه نیز از Honeypot، زمان‌سنج امضاشده، محدودیت لینک و Rate Limit استفاده می‌کند.
